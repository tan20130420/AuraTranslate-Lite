# AuraTranslate Lite

基于 [cai2761m/Auratranslate](https://github.com/cai2761m/Auratranslate) v0.3.2（MIT）改造。
原项目是「AI 双语翻译 + 字幕」的完整工具，需要自备大模型 API Key。这一版删掉了 AI 相关的复杂部分，补上了一个轻量复习功能，目标是：**看 YouTube 学英语，遇到生词存下来，隔几天能复习**。

## 和原版的区别

### 删掉的

| 原功能 | 为什么删 |
|---|---|
| 翻译服务 / 供应商目录 / 模型选择 | 需要自备 API Key、管理多模型，和「看视频记单词」无关 |
| JSON 输出模式、LLM 深度上下文 | 只有 AI 翻译才有的选项 |
| AI 总结视频 | 又要 Key，又要等，学习场景用不上 |
| 智能断句（LLM 断句）、语音识别纠错 | 依赖大模型；没 Key 时还会报错 |
| 仓库里的旧安装包、`.idea` 配置 | 杂物 |

### 保留并变得更省事的

- **YouTube 双语字幕**：读视频自带字幕轨，译文和原文上下对照
- **悬浮字幕列表**：点任意一行跳到对应时间点，可搜索、可跟随播放
- **网页沉浸式翻译**：段落对照，可切「仅译文」
- **划词翻译**：选中任意文字即译，并把所在句子作为上下文一起收藏
- **本地生词本**：存在 `chrome.storage.local`，不登录、不上传，可导出 JSON / CSV

### 字幕也走免费源了

原版字幕翻译只走 AI，没 Key 就不能用。现在增加了一条降级链路：

```
有 AI 配置 → 走 AI（原行为不变）
没有 Key → 自动用 Google / Bing 免费接口
```

翻译源可以在设置页和弹窗里切换 Google / Bing。

**v0.4.1 修复**：内容脚本原本有一道 `hasApiKey()` 硬门槛，没 Key 时连翻译请求都不发，直接在字幕位置显示「请在扩展选项页填写 Custom API 配置」。现在这道门槛改成「有内置源就放行」，并且：

- 整批失败时按 **Google → Bing → MyMemory** 依次换源，并记住可用的那个（24 小时）
  - Google 失败时直接把超时从 15 秒降到 8 秒，避免首句卡太久
  - MyMemory 无需任何凭据，境内外都能访问，但匿名额度有限（约 5000 字符/天），只当最后兜底
- 缓存键不再因为“当前有无 Key”而漂移，避免填/清 Key 后已有字幕缓存全部失效

### 新增：四档复习

生词本多了一套不依赖 Anki 的复习机制：

- 每个词有 `step` 档位：**生疏 → 一般 → 熟悉 → 掌握**
- 点「开始复习」后，把到期的词打乱出卡
- 有例句时**挖空**（`Tiny habits ＿＿＿ over time.`），先回想再翻面
- 没有例句时，正面显示中文释义，回忆英文
- 翻面后三选一：
  - **忘记了** → 退回生疏，10 分钟后再来
  - **一般** → 升一档（1 天 → 3 天 → 7 天）
  - **很熟** → 升两档
- 升到「掌握」自动标记已掌握，不再进入复习队列
- 顶部统计会显示「今天待复习 N」

数据结构（`auraVocabulary` 的每条词条）：

```js
{
  id, sourceText, translatedText, sourceLanguage, targetLanguage,
  contextText,      // 例句上下文
  sourceUrl, sourceTitle, notes,
  learned,          // 是否已掌握
  step,             // 0 生疏 / 1 一般 / 2 熟悉 / 3 掌握
  reviewCount, lastReviewedAt, nextReviewAt,
  createdAt, updatedAt
}
```

## 安装

1. 解压到固定位置（不要放在临时目录）
2. Chrome / Edge 打开 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 「加载已解压的扩展程序」→ 选中包含 `manifest.json` 的文件夹

无需账号、无需 API Key。

## 使用

**看视频**：打开带字幕的 YouTube 视频 → 点播放器控制栏里的扩展按钮 → 字幕变成双语。点「悬浮字幕列表」可看全片字幕并跳转。

**悬停即停**：鼠标停在字幕上、或停在右侧推荐视频列表上，视频自动暂停；移开继续播放。你自己按过暂停的，移开不会替你播放。

**悬停查词**：鼠标停在字幕里的英文单词上约 0.26 秒，弹出音标、词性和中文释义，点「收藏」直接存进生词本，并自动带上这句字幕作为例句。同一个词重复出现会走缓存，不再请求网络。

这两项都在「设置 → 实时字幕 → 悬停交互」里可以单独关掉。

**存词**：在网页或字幕里选中文字 → 弹窗里点「收藏到生词本」，会一起保存所在句子。

**复习**：扩展图标 → 生词本 → 「开始复习」。也可以从设置页进入。

**备份**：生词本页可导出 JSON（可再导入）或 CSV（表格查看）。

## 开发

```bash
npm install          # 需要 Node 22+
npm run build        # 改完 ui/ 下的 React 源码后必须执行
node --test          # 跑测试
```

- `ui/` 是 React 源码，构建产物是 `options/options.js`、`popup/popup.js`、`src/ui/content-ui.js`，**不要直接改产物**
- `options/options.css` 是手工维护的，构建不覆盖
- 后台脚本是 classic script，按 `manifest.json` 里的顺序加载，新增文件要同步改 `src/background.js` 的 `importScripts` 和 manifest 的 `background.scripts`

## 已知限制

- 国内网络下首次翻译会先等 Google 超时（约 8 秒）再切到可用源，之后 24 小时内直接走可用源
- 悬停查词只查英文字幕行；把显示方式设成「仅译文」时没有英文单词可停，查词自然不触发
- 悬停查词走有道网页版接口，释义质量依赖它；接口变动时会退回 MyMemory，只给一句中文、没有音标

- **免费接口有频率限制**：Google 免 Key 接口触发限流会冷却 60 秒，此时切到 Bing，或等一会儿
- **长视频首次翻译较慢**：免费源是逐句请求，整片翻译要跑一段时间，之后走缓存
- **只支持 YouTube / Google Drive 视频**，B 站、Netflix 不在原项目范围内
- **测试环境**：`node --test` 有 16 项失败，全部是 jsdom / undici 与 Node 版本的兼容问题（要求 Node 22+），与功能无关；核心逻辑与新增的复习测试全部通过
- 沙盒环境连不上 YouTube，字幕抓取只做了代码层验证，实际播放页请自行确认
